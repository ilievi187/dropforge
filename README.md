# DropForge

**Drag & drop offline video, image & audio converter** for Linux built with Python + Qt 6 (`PySide6`) and `ffmpeg`, with smooth hover glow effects and **live Omarchy theme synchronization**.

[![License: MIT](https://img.shields.io/badge/License-MIT-7376b7.svg)](LICENSE)
[![Buy Me a Coffee](https://img.shields.io/badge/Support-Buy%20Me%20a%20Coffee-FFDD00?logo=buy-me-a-coffee&logoColor=black)](https://buymeacoffee.com/aurorauap)

## Features
- **Video:** Compress for Discord/Telegram, clean 1080p H.264 MP4, Video → Smooth GIF, Extract MP3 audio, Strip Audio (Mute).
- **Images:** Convert PNG / JPG / WebP, Resize to 1920px, Strip EXIF metadata for privacy.
- **Audio:** Convert MP3 (320k) / WAV / compact Opus.
- Shows exact Before → After file size savings and 1-click **Open Output Folder**.
- 100% offline — your files never leave your computer.
- Adapts live to your active Omarchy theme.

## Quick Start
```bash
git clone https://github.com/ilievi187/dropforge.git
cd dropforge
./run.sh
```
